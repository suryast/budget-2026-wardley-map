# Budget 2026 Wardley Map

Interactive Wardley maps for Australia's 2026 federal budget debate.

Live site:
- https://budget-2026-wardley-map.setiyaputra.me/
- https://budget-2026-wardley-map.setiyaputra.me/federal-state

GitHub:
- https://github.com/suryast/budget-2026-wardley-map

## What this is

This project maps Budget 2026 policy areas as visible voter-facing promises, delivery capabilities, and shared infrastructure. The goal is to show how a political commitment depends on coordination underneath it, especially across the federal-state boundary.

The `/federal-state` route is the clearest example. It traces Commonwealth commitments into state delivery systems, showing where the real implementation pressure sits.
